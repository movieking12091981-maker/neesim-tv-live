NEESIM TV LIVE — FREE STATIC WEBSITE

This website opens directly on the YouTube live player for the NEESIM TV channel.
It is designed for free static hosting such as GitHub Pages.

PUBLISH WITH GITHUB PAGES
1. Upload all files from this folder to the repository root (not the ZIP file itself).
2. Open repository Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish. Your site address will be shown in Settings → Pages.

IMPORTANT
- The embedded YouTube live player displays the channel's live broadcast when YouTube exposes an active stream.
- The YouTube channel must be public and the live stream must allow embedding.
- The RTMP ingest address is not a viewer playback address.
- If the channel is not live, YouTube may show that no live stream is available.
- GitHub Pages and this starter website are free; a custom domain name may cost money.

INSTALL ON PHONE
- Android/Chrome: open the published website, then use the browser menu → Install app or Add to Home screen.
- iPhone/Safari: open the published website, tap Share → Add to Home Screen.
